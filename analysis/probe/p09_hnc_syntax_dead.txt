结论（CLOSED）:
  1. CreateHncTextGroup 只构造 **CFWordLib**，不构造 CSentenceObj。
  2. 全部工作 = 分配 0x1004a0 字节 + 构造 CFWordLib + LoadLib(FalunWord.lib)
     + 把两个整数参数(2,3)存进对象字段。
  3. 返回值 = 全局对象 + 0x124，与 GDE harness 观测到的 "g-0x124=主对象" 完全吻合。
  4. **产品通过 IHncTextGroup 拿到的能力 = 词库查询（CFWordLib），
     不包含任何句法分析（CSentenceObj 整条链未被实例化）。**

辅助证据:
  - 全树检索 GetSentenceALC / MakeSentSC / CutWordMax / MakeObjFromJK / MakeObjFromSri /
    MakeALC / CorpGroup 这些名字，**只出现在 SentenceObj.dll 自身**（作导出名）。
    Handler.dll / HncEng.exe 连 GetProcAddress 字符串都没有。
  - 8 个句法函数的地址在任何 vtable / 指针表中出现 0 次（PTR-REF:0）。
