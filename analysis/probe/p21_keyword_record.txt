# 关键词记录 144B 结构与规则语法（P7 成果）

## 结论

### 记录结构（144 字节 = 0x90）

| 偏移 | 字段 | 说明 |
|---|---|---|
| +0x00 | 规则字符串 | `{词1,词2}[字1,字2]` 格式（Surfgd 直接当字符串指针用） |
| +0x84 | 有效标志 | 1=有效（XNet2 侧检查 `[ebp+0x80]` 即 `[记录+0x84]`） |
| 其余 | 填充/预留 | — |

### XNet2 内部结构 vs 下发结构

- XNet2 内部：`[+0]=4字节头, [+4]=字符串, [+0x84]=标志`
- 下发时：SG_Control 传 144 字节，Surfgd 侧记录 `[+0]` 就是字符串

### 规则语法（Surfgd 匹配引擎 0x1000219e 解析）

| 字符 | 码 | 含义 |
|---|---|---|
| `{` | 0x7b | 组开始（多组间是"与" AND 关系） |
| `}` | 0x7d | 组结束 |
| `[` | 0x5b | 字符类开始（同类，可含多词） |
| `]` | 0x5d | 字符类结束 |
| `,` | 0x2c | 词分隔符（同组多词是"或" OR 关系） |

### 匹配引擎（0x1000219e）逻辑

- 数据结构：5 组 × 每词 0x50(80) 字节缓冲
- 组计数 [ebp-0x101c]，词计数 [ebp-0x1020]，字符位置 [ebp-0x1018]
- 5 层嵌套循环：遍历所有组的词组合
- 每组词用 strstr(0x1000a8a0) 匹配目标文本
- 全部组命中 → 返回 1（规则命中）

### 规则示例（语义推断）

`{成人,色情}[网站,论坛]` = （含"成人"或"色情"）且（含"网站"或"论坛"）

### 三名单记录格式对比

| 名单 | 语义 | 记录内容 |
|---|---|---|
| A | 出站URL | URL/域名字符串 + 标志 |
| B | 监控进程 | 进程名 + 标志 |
| C | 入站关键词 | **多组规则**（{}[]语法）+ 标志 |

## 关键数据

| 项 | 值 |
|---|---|
| 记录大小 | 144 (0x90) |
| 名单A容量 | 1000 条（0x23280/144） |
| 名单B容量 | 100 条（0x3840/144） |
| 名单C容量 | 1000 条（0x23280/144） |
| 单条添加上限 | 11000 条（0x2af8，命令码0x32） |
| XNet2 内部数组 | 0x182b80 = 11000×144（完整容量） |
