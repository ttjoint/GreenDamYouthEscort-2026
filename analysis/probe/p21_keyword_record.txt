# 关键词记录 144B 结构与规则语法（P7 成果）

## 结论

### 记录结构（144 字节 = 0x90）

| 偏移 | 字段 | 说明 |
|---|---|---|
| +0x00 | 规则字符串 | `{词1,词2}[字1,字2]` 格式（Surfgd 直接当字符串指针用） |
| +0x84 | 有效标志 | 1=有效（XNet2 侧检查 `[ebp+0x80]` 即 `[记录+0x84]`） |
| 其余 | 填充/预留 | — |

### XNet2 内部结构 vs 下发结构

- XNet2 内部：`[+0]=4字节头, [+4]=字符串, [+0x84]=标志`
- 下发时：SG_Control 传 144 字节，Surfgd 侧记录 `[+0]` 就是字符串

### 规则语法（Surfgd 匹配引擎 0x1000219e 解析）

| 字符 | 码 | 含义 |
|---|---|---|
| `{` | 0x7b | 组开始（多组间是"与" AND 关系） |
| `}` | 0x7d | 组结束 |
| `[` | 0x5b | 字符类开始（同类，可含多词） |
| `]` | 0x5d | 字符类结束 |
| `,` | 0x2c | 词分隔符（同组多词是"或" OR 关系） |

### 匹配引擎（0x1000219e）逻辑

- 数据结构：5 组 × 每词 0x50(80) 字节缓冲
- 组计数 [ebp-0x101c]，词计数 [ebp-0x1020]，字符位置 [ebp-0x1018]
- 5 层嵌套循环：遍历所有组的词组合
- 每组词用 strstr(0x1000a8a0) 匹配目标文本
- 全部组命中 → 返回 1（规则命中）

### 规则示例（语义推断）

`{成人,色情}[网站,论坛]` = （含"成人"或"色情"）且（含"网站"或"论坛"）

### 三名单记录格式对比

| 名单 | 语义 | 记录内容 |
|---|---|---|
| A | 出站URL | URL/域名字符串 + 标志 |
| B | 监控进程 | 进程名 + 标志 |
| C | 入站关键词 | **多组规则**（{}[]语法）+ 标志 |

## 关键数据

| 项 | 值 |
|---|---|
| 记录大小 | 144 (0x90) |
| 单条添加总上限 | 11000 条（0x2af8，@0x1746） |
| XNet2 内部数组 | 0x182b80 = 11000×144（完整容量） |

## 容量与命令码对照（**已按代码实测修正**）

> **更正（本轮）**：本节原先把「0x23280/144=1000」记成名单 A、「0x34bc0/144=1500」
> 也记成名单 A，两处都错。实测 `cmp [计数], imm` 得到下表；
> `0x23280` 是名单 C 的**字节数**（1000×144），`0x34bc0` 是名单 D 的（1500×144）。

| 名单 | 基址 | 计数全局 | **上限** | 上限证据 | 命令码 |
|---|---|---|---|---|---|
| A | 0x1021bf18 | 0x10228120 | **100** (0x64) | `cmp [0x10228120],0x64` @0x2d34 | 0x192 设置 / 0x193 读 / 0x194 增 / 0x195 删 |
| B | 0x102186d8 | 0x10228124 | 无显式常量 | 仅 `cmp edx,[0x10228124]` 循环边界 | 0x1ba / 0x1bb / 0x1bc / 0x1bd |
| C | 0x1003db80 | 0x1022811c | **1000** (0x3e8) | `cmp [0x1022811c],0x3e8` @0x1acd | 0x78 |
| D | 0x10060e0c | 0x1022812c | **1500** (0x5dc) | `cmp [0x1022812c],0x5dc` @0x27b5 | 0x118 设置 / 0x279b 增 / 0x2896 删 |

命令码 → 实现函数（转发追踪实测）：

| 命令码 | 转发目标 | 操作名单 |
|---|---|---|
| 0x192 / 0x193 | 0x2f82 / 0x2f23 | A |
| 0x194 / 0x195 | 0x2d1a,0x2e01,0x2f82 / 0x2e01,0x2f82,0x2f23 | A |
| 0x1ba / 0x1bb | 0x32a7,0x3248 / 0x3248 | B |
| 0x1bc / 0x1bd | 0x301b,0x3102,0x32a7 / 0x3102,0x32a7,0x3248 | B |
| 0x078 | 0x1d6c | C |
| 0x118 | 0x1a54,0x279b,0x2896 | D |
| 0x050 | 0x19f5,0x1a54,0x279b | C+D（批量） |

> 注：XNet2 侧**不直接**调用 0x192 / 0x1ba（这两个是 SurfGd 内部码），
> XNet2 实际下发用的是 0x118（名单D）、0x1bb（名单B）、0x78（名单C）。
