# 图像过滤调用链（P8 成果）

## 结论：图像过滤 = 抓屏 + Haar人脸 + 颜色直方图(肤色) + 轮廓形状分析

## 完整调用链

```
xnet2.exe
  → CImage.dll!CAPSCREEN(魔法数校验)      抓屏
       → 0x100048e0                       抓屏核心
  → CImage.dll!CHECKEX2(0x7ab7, img, mode) 检测入口
       ├─ cmp [arg0], 0x7ab7              魔法数 31415
       │   └─ ≠ → Sleep(10000ms) + 返回0x64  ← 反调试
       └─ = → 0x10004a60(img, mode=1)     核心检测
             ├─ 3 种模式(1/3/其他) → 不同浮点阈值
             ├─ 0x10008de0                初始化检测器
             ├─ 0x10008e20                宽高比检查(宽/高 < 阈值)
             ├─ 0x10008e70                颜色直方图(256桶, RGB步进3)
             └─ 0x10008e10                清理
  → CImage.dll!DES2GO                      处理结果

FImage.dll (独立模块)
  → 引用 XFimage.xml @0x7030 = haarcascade_frontalface_alt2
  → 人脸检测（OpenCV Haar 级联）
```

## 三个导出函数（xnet2 → CImage.dll）

| 函数 | RVA | 签名推断 | 作用 |
|---|---|---|---|
| CAPSCREEN | 0x4970 | int CAPSCREEN(?) | 抓屏 |
| CHECKEX2 | 0x59f0 | int CHECKEX2(magic=0x7ab7, img, mode) | 图像检测入口 |
| DES2GO | 0x5ae0 | int DES2GO(?) | 处理结果 |

## 反调试机制

CHECKEX2 首参数必须 = 0x7ab7(31415)，否则：
```
Sleep(0x2710=10000ms)  ; 睡 10 秒
return 0x64(100)       ; 返回错误码
```

## OpenCV 函数使用（CImage.dll import）

### 图像预处理
- cvLoadImage, cvCvtColor(灰度), cvResize
### 边缘/形态学
- cvCanny, cvDilate, cvErode, cvMorphologyEx, cvNot
### 轮廓分析（形状检测）
- cvFindContours, cvApproxPoly, cvContourArea, cvArcLength, cvBoundingRect
- cvDrawContours, cvGetSeqElem, cvGetQuadrangleSubPix, cvMoments
### 线检测
- cvHoughLines2

## 检测算法组合

| 算法 | 实现 | 用途 |
|---|---|---|
| 颜色直方图 | 0x10008e70（256桶，步进3字节） | 肤色/色彩分析 |
| 宽高比 | 0x10008e20 | 图像合理性 |
| Haar 级联 | FImage.dll + XFimage.xml | 人脸检测 |
| 轮廓形状 | cvFindContours 系列 | 图形特征 |

## 关键浮点阈值（0x10004a60 三种模式）

| 模式 | 常量 | 值(约) |
|---|---|---|
| 1 | 0x3fbeb851 / 0x3fd33333 | 0.115 / 0.413 |
| 3 | 0x3faeb851 / 0x3fc47ae1 | 0.174 / 0.184 |
| 其他 | 0x3fb70a3d / 0x3fc99999 | 0.183 / 0.206 |

（这些是 Haar 检测器的 scale_factor / min_neighbors 相关参数）

## 复刻契约（图像过滤）

1. 抓屏（CAPSCREEN）→ 得到图像
2. CHECKEX2 检测（3 模式）：
   - 宽高比检查
   - 颜色直方图（肤色占比）
   - Haar 人脸检测（XFimage.xml）
   - 轮廓形状分析
3. 返回检测结果（0=干净, 非0=命中）
