# 图像过滤调用链（P8 成果）

## 结论：图像过滤 = 抓屏 + Haar人脸 + 颜色直方图(肤色) + 轮廓形状分析

## 完整调用链

```
xnet2.exe
  → CImage.dll!CAPSCREEN(魔法数校验)      抓屏
       → 0x100048e0                       抓屏核心
  → CImage.dll!CHECKEX2(0x7ab7, img, mode) 检测入口
       ├─ cmp [arg0], 0x7ab7              魔法数 31415
       │   └─ ≠ → Sleep(10000ms) + 返回0x64  ← 反调试
       └─ = → 0x10004a60(img, mode=1)     核心检测
             ├─ 3 种模式(1/3/其他) → 不同浮点阈值
             ├─ 0x10008de0                初始化检测器
             ├─ 0x10008e20                宽高比检查(宽/高 < 阈值)
             ├─ 0x10008e70                颜色直方图(256桶, RGB步进3)
             └─ 0x10008e10                清理
  → CImage.dll!DES2GO                      处理结果

FImage.dll (独立模块)
  → 引用 XFimage.xml @0x7030 = haarcascade_frontalface_alt2
  → 人脸检测（OpenCV Haar 级联）
```

## 三个导出函数（xnet2 → CImage.dll）

| 函数 | RVA | 签名推断 | 作用 |
|---|---|---|---|
| CAPSCREEN | 0x4970 | int CAPSCREEN(?) | 抓屏 |
| CHECKEX2 | 0x59f0 | int CHECKEX2(magic=0x7ab7, img, mode) | 图像检测入口 |
| DES2GO | 0x5ae0 | int DES2GO(?) | 处理结果 |

## 反调试机制

CHECKEX2 首参数必须 = 0x7ab7(31415)，否则：
```
Sleep(0x2710=10000ms)  ; 睡 10 秒
return 0x64(100)       ; 返回错误码
```

## 两个检测函数的精确逻辑（**实测重写，见下方更正**）

### 宽高比检查 `0x10008e20(width, height) -> int`

```
if width < 32 or height < 32:      ; 0x8e24/0x8e2d: cmp ...,0x20
    return 1                       ; 太小，不判异常
ratio = max(w,h) / min(w,h)        ; 0x8e32-0x8e44: fild/fidiv，先比大小再相除
if ratio < [0x1000dc48]:           ; fcomp qword
    return 0                       ; 过于细长 → 判异常
return 1
```

**`[0x1000dc48]` 实测 = 10.0（double）**，字节 `0000000000002440`。

### 颜色直方图 `0x10008e70(ptr, width, height) -> int`

```
hist[256] = 0.0                    ; 0x8e85-0x8e92: rep stosd 0x200 dword
for row in range(height):          ; 0x8e94-0x8ecf
    p = ptr + 2                    ; 0x8e99: lea edi,[eax+2] —— BGR 的 R 通道
    for col in range(width):
        hist[p[0]] += 1.0          ; 0x8ea4-0x8ec7: 取 1 字节，+[0x1000d518]=1.0
        p += 3                     ; 0x8ea6: add ecx,3 —— 步进 3 字节
    ptr += width * 3               ; 0x8ec9-0x8ecc
total = width * height
for i in range(256): hist[i] /= total   ; 0x8ed4-0x10008ef3: 归一化
low  = sum(hist[0   .. 0xd1])      ; 0x8f07: ecx=0xd2(210) 个桶
high = sum(hist[0xd2 .. 0xff])     ; 0x8f1f: ecx=0x2e(46) 个桶
if high / (low + high) >= [0x1000d540]:
    return 1
```

**`[0x1000d540]` 实测 = 0.9（double）**，字节 `cdccccccccccec3f`。
**`[0x1000d518]` 实测 = 1.0（double）**，字节 `000000000000f03f`。

### 更正：本节原先把这两个函数描述错了

| 原先写的 | 实际（本轮实测） |
|---|---|
| "宽高比阈值 0.115/0.413 等三组" | 宽高比只有一个阈值 **10.0** |
| "颜色直方图 = 肤色占比" | 是 **高亮度桶（R ≥ 210）占比 ≥ 0.9**，即过曝/白屏检测 |
| "0x10004a60 三种模式有不同浮点阈值" | 那三组常量不在 `0x10004a60`，是别处的；宽高比与直方图各自只有**一个**阈值 |

原先那句"这些是 Haar 检测器的 scale_factor / min_neighbors 参数"是**推断**，
本轮未能在代码中找到依据，已删除。Haar 确实存在（`FImage.dll` 引用
`XFimage.xml`），但它与这两个函数的阈值无关。

## 复刻契约（图像过滤，按实测重写）

| 步骤 | 函数 | 判据 | 证据 |
|---|---|---|---|
| 1 | `0x10008e20` | 短边 < 32 → 放行；长/短 ≥ 10.0 → 异常 | 0x8e20-0x8e5f |
| 2 | `0x10008e70` | R 通道 ≥ 210 的像素占比 ≥ 0.9 → 异常 | 0x8e70-0x8f4e |
| 3 | `FImage.dll` + `XFimage.xml` | Haar 人脸检测 | 字符串引用 @0x7030 |

三者是**独立判据**，任一命中即"可疑"。原厂 `CHECKEX2` 把它们串起来，
返回 0=干净 / 非 0=命中。
