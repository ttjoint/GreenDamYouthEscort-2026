# 名单 D 与查询命令（P10 成果）

## 名单 D（第4个名单，之前遗漏）

| 项 | 值 |
|---|---|
| 基址 | 0x10060e0c |
| 计数 | 0x1022812c |
| 容量 | 1500 条（0x5dc） |
| 记录 | 144 字节，字符串在 +4 |
| 匹配 | 小写化 + strcmp（添加去重）/ strstr（查询） |
| 临界区 | 0x10225dc8（线程安全） |

操作函数：
- 添加 @0x279b：去重检查 + 小写化 + 加入
- 删除 @0x2896：strcmp 匹配 + memmove 前移
- 查询 @0x2cc0：strstr 匹配，命中返回0/未命中返回1

## 查询命令码语义补充

| 命令码 | 语义 | 实现 |
|---|---|---|
| 0xfa0 | 查询字符串是否在名单D | 0x2cc0（strstr，返回0=命中） |
| 0xfa1 | 查询（另一结果） | 0x2c39（strlen相关） |
| 0xbc2 | strlen（字符串长度） | 0x9f30（标准strlen优化） |

## XNet2 查询调用模式

```
0xfa0: cmp [状态码], 0x64(100) → 查询 → 读返回标志
0xfa1: cmp [状态码], 0x12c(300) → 查询 → 读返回标志
```

状态码 100/300 可能是 HTTP 状态或内部错误码。

## 完整名单体系（修正后，共4个名单）

| 名单 | 基址 | 语义 | 容量 | 使用方 |
|---|---|---|---|---|
| A | 0x1021bf18 | 出站 URL/协议指纹 | 1500 | DBFP_Send |
| B | 0x102186d8 | 监控进程名 | 100 | DBFP_Socket |
| C | 0x1003db84 | 入站关键词 | 1000 | DBFP_Recv |
| D | 0x10060e0c | 运行时动态名单 | 1500 | SG_Control 0xfa0查询 |

名单 D 与 A/B/C 的区别：**有完整的运行时增删接口**（添加@0x279b/删除@0x2896），
且由查询命令 0xfa0 供 XNet2 动态查询。
