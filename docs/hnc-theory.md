### 3. 语义块标记符（本轮新增：`src/green_dam/chunk_tags.py`）

`[张]` 对俞士汶《现代汉语语法信息词典详解》介词表 85 选 76 + 外加 4，
人工分析 8,872 个标注句后给出三大表。工程价值（原文）：
**纯类标记符占 81%，程序可直接从介词判定语义块类型**。

落地内容：

- `TagRole`：MAIN / SECONDARY / DUAL 三角色 Flag，可叠加。
- `TAG_TABLE`：78 个唯一介词（口径说明见下），每个带论文原表写法、
  角色集、搭配型块尾（"拿……来说"等四组）。
- `maximal_tag_at`：文本位置处的最长匹配，供分块器切块首。
- `roles_of` / `tag_of`：查询接口。

**统计口径冲突（测试锚点已固定）**：论文说"80 个，主 32/辅 56/两可 9"，
但三张表逐项加总的唯一介词数是 78。行次口径下主=17+11+2+2=32、
辅=43+11+2=56，与论文吻合——即 **32/56 是行内列出次数**，"为（去声）/从"
三角色兼备被重复计入。纯类 17/43/5 与唯一数 78 两个口径都可在表上重建。

**边界**：这张表回答"介词标记哪个语义块"，不回答"句类码是什么"。
它是句类感知的前置层，与 `hnc.py`（句类判定）是上下游关系，不是替代。

### 3b. l 类概念的层级与 lv 准则（本轮新增：`src/green_dam/l_concepts.py`）

论文 11.1《语义块切分的基本准则：lv 准则》给出 l 类的一级分派：

```
l0, l2  → 主语义块指示符
l1, l3  → 辅语义块指示符
l4      → 语义块组合指示符（l41="的"、l42=of、l40=关系代词）
l8      → 辅语义块说明符（"根据"=lv8012l、"从"=lj80425、"到"=lj80426）
l6, la  → E 语义块说明符（l6 时态、la 逻辑态）
l9      → 指示代词（唯一不能直接切分、但常提示块首）
lb      → 句间说明符
```

这与 `chunk_tags.py` 是**正交**关系：前者是概念分类，后者是功能分类
（主/辅/两可）。`chunk_tags` 的 43 个纯辅介词在 l 类里全是 l1/l3；
而 l0/l2/l4/l6/l9/la/lb 在 `chunk_tags` 里根本没有对应项。

**这一节修正了 `chunker.py` 的一个准则性错误。** 原文：

> l 准则仅用于判定辅语义块，对主语义块的判定只有 v 准则可以利用。
> 所以，标准格式语句的主语义块切分通常反而比较困难。

早期实现正好相反——拿介词去切主块，结果辅块一路延到分句尾，
把谓语吃掉了：

```
我们班同学在教室里认真地看书
修前：B(我们班) + B(学) + Cn(教室里认真地看书)   ← 谓语被吞
修后：B(我们班同学) + Cn(教室里认真地) + E(看书)
```

修正方式：辅块右边界改由 **v 信号**（体标记 着/了/过、状语尾 地）
定位，而不是由 l 标记自己延到分句尾。见 `_predicate_start()`。

**边界**：原文只给了 l0–l9 的**分派**，没有给每个节点下辖的词表
（那在未出版的《HNC 概念符号体系手册》里）。所以 `L_TABLE` 只把
原文正文点名的少数几个标为 `attested=True`，其余由 `chunk_tags`
的功能分类回填并标 `attested=False`。l1 与 l3 的判别标准原文未给，
本实现**不硬分**，统一记 l1。

### 3c. 语义块的数学表示（论题 34）

论题 34《语义块表示式及其应用》给出四类块的物理/数学对照：

| 语义块类型 | 物理表示 | 数学表示 |
|---|---|---|
| 特征语义块 | X, P, T, Y, R, S, D, jD | E |
| 广义对象语义块 | A, B, C | JK, JKm, JKn |
| 辅语义块 | Ms, In, Wy, Re, Cn, Pr, Rt | fK, fKm, fKmn |
| 两可语义块 | RtB, ReC | fJK, fJKm, fJKmn |

落地为 `ChunkRole.math_symbol` 与 `Chunking.math_pattern()`，后者输出
晋耀红式 (2.1) 的形式：

```
FJ = Σk(JKi) + E + Σm(JKi)

张三打断了李四的腿  →  JK + E + JK
他拍着手笑          →  JK + E        （Ms 不进结构式）
```

**边界**：`X/P/T/Y/R/S/D/jD` 这 8 个特征句类**没有落地**——它们要
由 E 块的概念类别决定，而那一层在缺失的 `JiBenJL.lib` 里。当前
所有 E 块一律记 `E`，不细分句类。两可块（RtB/ReC）同样不产出。

### 4. 句类相似度计算（`[王]`，下一步可实现）

`[王]` 证明了 HNC 句类知识在工程上有可测收益（AP@1 0.67 / MAP 0.72 /
MRR 0.77，胜过 VSM/语言模型/翻译模型），其计算公式**不依赖缺失字典**：

```
sim(Q,C) = α·sim_cat + β·sim_gse + γ·sim_sem     （式 1）
sim_gse  = β1·sim_gsem + β2·sim_gsef             （式 3，主辅块句类符号）
sim_sem  = γ1·sim_semm + (1-γ1)·sim_semf         （式 6，主辅块内容）
```

调优后权重：α=0.3 β=0.3 γ=0.4 β1=0.7 β2=0.3 γ1=0.8；
分项细则：同句类=1、同广义作用/效应句=β11(0.5)、辅块同符号同内容=1、
同符号异内容=β21(0.7)、符号相交=β22(0.4)、否则 0。

对本项目的意义：M3 双后端 A/B 测量（architecture.md P3）一直缺一个
**句级**度量。`[王]` 的公式可以直接当 HncBackend 的句相似度接口，
让"复刻的句类判定 + 词库命中"输出可比较的分值，而不是只输出布尔拦截。

## 对重构路线的修订

原路线（architecture.md P3）只说"两个后端 A/B"。读过三份文献后，
HNC 这一侧的可达上限更清楚了，修订如下：

1. **已完成**：句类判定器复刻（`hnc.py`，二进制级等价）。
2. **本轮新增**：语义块标记符表（`chunk_tags.py`），句类感知前置层。
3. **下一步**（P3 前置）：`SentenceChunker`——用标记符表切辅块边界 +
   实词首（"v+着"）启发式，输出语义块序列，喂给 `hnc.classify`。
4. **再下一步**：按 `[王]` 式 1/3/6 实现 `sentence_similarity`，
   作为 M3 A/B 的句级度量。
5. **不做**：五元组/挂靠/具体概念网络。绿坝场景用不上，且无数据可校准。

## 诚实边界（2026 修订）

### 仍不可还原

- **`!31116` 类数字码 → `X22` 类字母码的映射**：原书（论题 16）给出
  的是字母码体系 `X22J=X2B+X22+XAC`，绿坝用的是自己的一套数字码。
  两者找不到公开对照表。可以引用字母码作标签，但不能反推。
- 逐词正常/拦截标志：不可还原（`FMean.tmp` 缺失）。
- 语法组合规则：不可还原（`rule.lib`/`TYPE.LIB`/`XU.LIB` 缺失）。

### 已由原始文献解决

- 语义块与句类的**术语定义**：附表 1/2 原文。
- 辅块判定三原则：论题 7 原文，已落到 `chunker.py`（见
  `tests/test_chunker.py::TopicSevenTest`）。
- 57/3192 句类总数：附表 2 原文确认，不再是二手引用。

### 仍然只能靠转述

- `[张]` 的表是人工分析结论，论文未给出 8,872 句的标注语料本身，
  表项无法机读复核——只能逐项对照原图，已做。
- 原书多处在谈方法论与学术史（如论题 7 大半是答问体），可直接工程化
  的硬结论没那么多。已抽取的已在 `data/hnc_archive/README.md` 索引。
