### 3. 语义块标记符（本轮新增：`src/green_dam/chunk_tags.py`）

`[张]` 对俞士汶《现代汉语语法信息词典详解》介词表 85 选 76 + 外加 4，
人工分析 8,872 个标注句后给出三大表。工程价值（原文）：
**纯类标记符占 81%，程序可直接从介词判定语义块类型**。

落地内容：

- `TagRole`：MAIN / SECONDARY / DUAL 三角色 Flag，可叠加。
- `TAG_TABLE`：78 个唯一介词（口径说明见下），每个带论文原表写法、
  角色集、搭配型块尾（"拿……来说"等四组）。
- `maximal_tag_at`：文本位置处的最长匹配，供分块器切块首。
- `roles_of` / `tag_of`：查询接口。

**统计口径冲突（测试锚点已固定）**：论文说"80 个，主 32/辅 56/两可 9"，
但三张表逐项加总的唯一介词数是 78。行次口径下主=17+11+2+2=32、
辅=43+11+2=56，与论文吻合——即 **32/56 是行内列出次数**，"为（去声）/从"
三角色兼备被重复计入。纯类 17/43/5 与唯一数 78 两个口径都可在表上重建。

**边界**：这张表回答"介词标记哪个语义块"，不回答"句类码是什么"。
它是句类感知的前置层，与 `hnc.py`（句类判定）是上下游关系，不是替代。

### 4. 句类相似度计算（`[王]`，下一步可实现）

`[王]` 证明了 HNC 句类知识在工程上有可测收益（AP@1 0.67 / MAP 0.72 /
MRR 0.77，胜过 VSM/语言模型/翻译模型），其计算公式**不依赖缺失字典**：

```
sim(Q,C) = α·sim_cat + β·sim_gse + γ·sim_sem     （式 1）
sim_gse  = β1·sim_gsem + β2·sim_gsef             （式 3，主辅块句类符号）
sim_sem  = γ1·sim_semm + (1-γ1)·sim_semf         （式 6，主辅块内容）
```

调优后权重：α=0.3 β=0.3 γ=0.4 β1=0.7 β2=0.3 γ1=0.8；
分项细则：同句类=1、同广义作用/效应句=β11(0.5)、辅块同符号同内容=1、
同符号异内容=β21(0.7)、符号相交=β22(0.4)、否则 0。

对本项目的意义：M3 双后端 A/B 测量（architecture.md P3）一直缺一个
**句级**度量。`[王]` 的公式可以直接当 HncBackend 的句相似度接口，
让"复刻的句类判定 + 词库命中"输出可比较的分值，而不是只输出布尔拦截。

## 对重构路线的修订

原路线（architecture.md P3）只说"两个后端 A/B"。读过三份文献后，
HNC 这一侧的可达上限更清楚了，修订如下：

1. **已完成**：句类判定器复刻（`hnc.py`，二进制级等价）。
2. **本轮新增**：语义块标记符表（`chunk_tags.py`），句类感知前置层。
3. **下一步**（P3 前置）：`SentenceChunker`——用标记符表切辅块边界 +
   实词首（"v+着"）启发式，输出语义块序列，喂给 `hnc.classify`。
4. **再下一步**：按 `[王]` 式 1/3/6 实现 `sentence_similarity`，
   作为 M3 A/B 的句级度量。
5. **不做**：五元组/挂靠/具体概念网络。绿坝场景用不上，且无数据可校准。

## 诚实边界（不变项）

- 句类码 → 自然语言语义：不可还原（`SENTEN.LIB` 缺失）。
- 逐词正常/拦截标志：不可还原（`FMean.tmp` 缺失）。
- 语法组合规则：不可还原（`rule.lib`/`TYPE.LIB`/`XU.LIB` 缺失）。
- `[张]` 的表是人工分析结论，论文未给出 8,872 句的标注语料本身，
  表项无法机读复核——只能逐项对照原图，已做。
