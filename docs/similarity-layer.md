# 句子相似度接入（A 阶段，已实现）

`src/green_dam/simpath.py`。测试 `tests/test_simpath.py` 35 项 +
`test_cli.py::SimilarCliTest` 6 项。

## 1. 接入前先发现并修掉的缺陷

`similarity.py`（291 行）此前完全没被使用。接入前实测发现**区分度不足**：

| 对 | 修前得分 |
|---|---|
| 同义改写 | 0.346 |
| 同结构无关 | 0.275 |

**差值只有 0.07**——阈值无论定在哪里都会同时放过两者。

### 根因：空集被判为"完全相同"

```python
if not qs and not cs:
    sim_gsef = 1.0      # ← 双方都没辅块
```

这给**每一对无辅块的句子**固定加 `β2=0.3` 分。

语义错误：两句话都没有辅块，说明**这个维度对它们不适用**，不是说明它们一致。
论文式 (5) 只定义了"同符号同内容=1"等情形，**未定义"双方皆无"**——所以这不是
偏离原文，是补齐原文未覆盖的分支。

`_aligned_mean` 里有同样的 `if not a and not b: return 1.0`，一并改为 `0.0`。

### 修后

| 对 | 修前 | 修后 |
|---|---|---|
| 完全相同 | 0.700 | **0.530** |
| 近义改写 | — | **0.370** |
| 被动改写 | 0.346 | **0.176** |
| 同结构无关 | 0.275 | **0.105** |
| 完全无关 | 0.105 | **0.105** |

近义改写与同结构无关的差值从 0.07 扩大到 **0.265**，阈值终于有意义了。

## 2. 阈值来自测量，不是猜测

```
0.2
```

| 对 | 分数 | 是否判为相似 |
|---|---|---|
| 完全相同 | 0.530 | ✓ |
| 近义改写（认真→仔细） | 0.370 | ✓ |
| 被动改写 | 0.176 | ✗ |
| 同结构无关 | 0.105 | ✗ |

## 3. 一个刻意不修的局限：被动改写漏判

`张三打断了李四的腿` vs `李四的腿被张三打断` 得 **0.176**，低于阈值。

原因：`char_overlap_similarity` 用**字符二元组 Jaccard**，对语序敏感。

**没有为了让这个样例通过而调低阈值。** 那样做等于用手选样例反向拟合参数，
而真正需要的是**真正的词汇语义相似度**——那在 `similarity.py` 里本来就是
替代实现，已标在 `degraded` 里。

测试 `test_passive_rewrite_falls_just_below_threshold` **钉住了这个局限**，
并断言它仍明显高于无关句（>0.15）。

## 4. 分块质量不足时拒绝评分

这是本模块最重要的设计。

`chunker` 的动词表有 413 条（从语料抽取），**不可能覆盖所有谓语**。
`王五擦干净了桌子` 因为"擦"不在表里，被切成单个 `B` 块。

此时结构项（`sim_gsem`/`sim_gsef`）描述的是**句子并不具备的形状**，
总分无意义。

```python
is_scorable(left, right) -> (bool, reason)
```

| 情况 | reason |
|---|---|
| 任一方太短（<2 字） | `too_short` |
| 任一方无分块 | `no_structure` |
| 任一方无谓语块 | `degraded_chunking` |

拒绝时返回 `scored=False`、`total=0.0`，**不返回一个看起来合理的数字**。

CLI 直接体现：

```bash
$ green-dam similar --left "张三打断了李四的腿" --right "王五擦干净了桌子"
scored     : False
reason     : degraded_chunking
  (a pair the chunker cannot structure is refused, not scored)
```

这是项目一贯原则的又一次应用：**判不了 ≠ 判为干净**。

## 5. 证据等级

```python
Finding(levels=(0,), action=None, attested=False, reason="similar_to_watched")
```

| 字段 | 值 | 理由 |
|---|---|---|
| `level` | 0 | 相似度不是危害等级 |
| `action` | None | 分→动作 映射未还原 |
| **`attested`** | **False** | 三个分项里**两个是替代实现** |

`attested=False` 是这里与分块层的关键区别：`chunkpath` 的 `attested=True`
（分块输出是测量），而相似度的 `sim_cat` 和 `sim_sem` 是替代算法，
`similarity.py` 自己在 `degraded` 里列出来了。

## 6. 日志安全

`Comparison.to_dict()` 只有数值、标志和 `degraded_terms` 的**计数**：

```json
{"total": 0.37, "threshold": 0.2, "similar": true,
 "scored": true, "reason": "", "degraded_terms": 2, "metrics": {...}}
```

测试断言句子片段不出现在摘要里。CLI 同样不回显句子。

## 7. 验收（41 项）

| 组 | 覆盖 |
|---|---|
| 可评分 | 结构化可评、太短、空、无结构、**无谓语被拒** |
| 对比 | 相同、改写高于无关、**被动改写略低于阈值（局限被钉住）**、无关低于阈值、**改写与无关差值 >0.2**、阈值可配、degraded 上报、指标为浮点 |

| 日志安全 | 摘要无文本、dict 可序列化、不可评也可序列化 |
| 诚实边界 | **完全相同但不可分块仍被拒**、阈值不硬编码 |
| CLI | 评分、拒绝、JSON、**不回显句子**、缺句报错、阈值覆盖 |
