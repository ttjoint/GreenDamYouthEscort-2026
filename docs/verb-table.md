# 动词表：从 208 条扩到 428 条，退化率降 13–15 个百分点

## 问题

`docs/corpus-eval.md` 记录：真实语料上 **99.9% 的单块退化是「无谓语候选」**。
分句器找不到谓语，只能把整句退回成一个无标记块。

根因不是「算法错」，而是**动词表太小**：

```
DEFAULT_VERBS = 208 条
  ├─ 双字 202 条
  └─ 单字   6 条（吃 哭 坐 睡 站 笑）
```

汉语单字动词（看/说/走/买/拿/做/去/来）**几乎全缺**。
一份 208 条的词表不可能覆盖真实语料。

## 做法：用体标记自动抽

「动词 + 着/了/过」是汉语的体形态标记，可靠度远高于猜：

```
看着 -> 看      笑了 -> 笑      说过 -> 说
```

`tools/harvest_verbs.py` 扫语料，`tools/build_verb_table.py` 生成
`data/verb-table.json`。

### 噪声过滤（实测更新）

直接抽噪声很大。前 40 名里就有 `不过`、`接着`、`向着`、`为了`、`太大了`。
规则和依据：

| 规则 | 例子 | 依据 |
|---|---|---|
| 连词/介词黑名单 | `不过` `接着` `为了` `除了` | `过`/`着` 是词素不是体标记 |
| 代词黑名单 | `什么` `怎么` `自己` | 不是动词 |
| 程度副词开头 | `太大了` `真好看` | 形容词 |
| 粘着前字 | `的看` `只不` `头看` `受不` | 切到了词中间 |

### 频次门槛是关键

| 门槛 | 条数 | 结果 |
|---|---|---|
| 30 | 5,354 | ❌ **14 个回归测试失败**（`认真` 38 次、`原因` 71 次被当动词） |
| 500 | 428 | ✅ 全部通过，且有效 |

低频候选噪声占绝大多数：`认真`(38)、`原因`(71) 这类词虽然**能**带体标记，
但语料里出现得太少，抽出来多半是别的原因。

## 效果

`tools/diagnose_chunker.py --limit=30`（各 30 个文件）：

| 语料 | 208 条 | 428 条 | 改善 |
|---|---|---|---|
| 普通小说 | 56.6% | **41.4%** | −15.2pp |
| 成人语料 | 64.5% | **50.9%** | −13.6pp |

对照：仅修分句（引号/碎片/连词粘合）只从 66.7% 降到 57.7%（−9pp）。
**动词表是更大的杠杆。**

## 但默认关闭

```python
SentenceChunker()                    # 208 条，原行为
SentenceChunker(extended=True)       # 428 条
```

原因：扩展表引入了两类**新**的切分错误，回归锁还没解决。

### 错误 1：`带` 抢了 `离开`

```
输入：日本代表带着满意的笑容离开会场
208 条：A[日本] E[代表] B[带着满意的笑容离开会场]     ← 至少 E 是对的
428 条：A[日本] E[代表带着] B[满意的笑容离开会场]      ← E 错了
```

`带` 进了表，它在 `带着` 处先命中，`离开` 就没机会。
这说明**单字动词和"v+着"降级规则（`[张]` §3）有冲突**：
§3 说 `v+着` 的首动词应降为辅块，但要先知道 `代表` 是 E 才行。

### 错误 2：`分析问题` 被整体当 E

```
输入：他正在分析问题
208 条：A[他正在] E[分析] B[问题]
428 条：A[他正在] E[分析问题]                       ← B 丢了
```

`问题` 不在动词表里，但 `_predicate_start` 的回溯把 E 的右边界推到了句末。
这是 `_predicate_start` 的既有缺陷，扩展表只是让它更常触发。

## 结论

- **扩展表值得用**（退化率收益 −15pp 是实打实的）。
- **但不能直接开**，要先修 `_predicate_start` 的右边界和 `v+着` 的优先级。
- 等这两个修好，再考虑把 `extended=True` 变成默认。

## 复现

```bash
# 抽动词表（约 3 分钟）
python tools/build_verb_table.py

# 对照退化率
python tools/diagnose_chunker.py --limit=30
python tools/diagnose_chunker.py --limit=30 --extended
```

## 追加：默认开启，以及两个缺陷的修法

### 之前的两个阻塞

扩展表早就建好了，但一直是 `extended=False`，因为两组句子会切错：

| 句子 | 错误切分 | 原因 |
|---|---|---|
| `他正在分析问题` | `E=分析问题` | `问题` 在表里（从 `问题了` 抽的），名动兼类 |
| `日本代表带着满意的笑容离开会场` | `A=日本` `E=代表带着` | `代表`/`带着` 抢了 E |

### 修法一：名动兼类排斥表

`harvest_verbs.NOUN_AMBIGUOUS`——明确列出「能带体标记但主要用法是名词」的词：

```
问题 事情 东西 时候 地方 意思 机会 时间 生活 心情 样子 眼神
代表 组织 决定 计划 报告 记录 影响 关系 感觉 印象 结论 标准
要求 希望 需要 建议 意见 想法 说法 看法 做法 行为 动作 反应
语言 声音 力气 味道 颜色 温度 速度 高度 长度 宽度 深度
```

**为什么不用「体标记次数 / 总次数」的比例门槛？** 试过，不可靠：

| 词 | 体标记 | 总次数 | 比例 |
|---|---|---|---|
| 离开 | 3,540 | 15,946 | 0.22 |
| 发生 | 6,265 | 14,906 | 0.42 |
| 问题 | 893 | 15,931 | 0.06 |
| **看** | **8,838** | **201,627** | **0.04** |

`看` 是典型动词，比例只有 0.04（大量作补语：`看见`/`看到`/`看起来`）。
任何能砍掉 `问题`(0.06) 的门槛都会连带砍掉 `看`(0.04)。

所以用**显式清单**。判据是「主要用法是名词」，不是「不能作动词」——
`问题` 确实能说「问题了」，但那是少数用法。

### 修法二：`_strip_zhe_companion`

`[张]` §3 的 `v+着+v`：前一个动词降为方式辅块。

早期版本用 `_zhe_prefix_end()` 单独做形状检测，只处理「V+着」紧贴 E 的情形
（`他拍着手笑`）。但 `日本代表带着满意的笑容离开会场` 中间隔了宾语，
那条路走不通，`_pick_e` 退回 `verbs[0]`，得到 `E=带着`。

现在改成**先整体剔除句首伴随动词**，再走正常流程：

```
输入: 日本代表带着满意的笑容离开会场
verbs: [(4,5) 带] [(11,13) 离开]
       ↑ `带着` 在表里只存词干 `带`
剔除: 判定 `带`(4,5) 后面紧跟 `着` -> zhe_end=6
      rest = [(11,13) 离开]
输出: A=日本代表 / BK_MS=带着满意的笑容 / E=离开 / B=会场
```

三个细节：

1. **判据是「V 后面紧跟「着」」**，不是「V 的末字是「着」」——词表存的是词干。
2. **要扫前几个动词**，不能只看 `verbs[0]`：`extended=True` 时 `代表` 也在表里。
3. **辅块延到 E 之前**：`拍着` 的宾语 `手`、`带着` 的宾语 `满意的笑容` 都在辅块内部。
   早期版本把 `手` 切成独立 B，`math_pattern()` 就从 `JK + E` 变成 `JK + JK + E`。
4. **形状兜底**：`他拍着手笑` 里 `拍` 不在表里（单字动词），
   所以最后按形状认「句首 6 字内的 X着」。

### 现在的效果

| 语料 | 单块退化（旧表） | 单块退化（扩展表） | 改善 |
|---|---|---|---|
| 普通小说 | 54.3% | **41.0%** | −13.3pp |
| 成人语料 | 66.9% | **52.5%** | −14.4pp |

分句数：普通 18,889、成人 11,878（与词表无关，由分句层决定）。

### 顺带修好的四句

以前在 `KNOWN_UNCHUNKED` 里，现在扩展表认得出谓语了：

```
看着这个行星上存在了五千年的文明
它曾经历过比这大得多的巨变
他们不想惹麻烦
那个地球表面可以看得更细了
```

它们已移到 `FIXED_BY_EXTENDED_TABLE`，并另加一条对照测试
`test_old_table_still_fails_on_those`——关掉扩展表后这几句必须仍然失败，
否则说明「改善来自扩展表」这个归因是错的。

### 仍然找不到谓语的（`KNOWN_UNCHUNKED`）

```
被毛毛虫国吞并
周围还有一圈亮着屏幕的电脑
他们还能干什么呢
劳动强度更大
这孩子学得很快
```

`被…吞并` 需要被动结构分析，`劳动强度更大` 是形容词谓语，
`学得很快` 是「V 得 补语」结构。都不是加词能解决的。
