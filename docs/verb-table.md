# 动词表：从 208 条扩到 428 条，退化率降 13–15 个百分点

## 问题

`docs/corpus-eval.md` 记录：真实语料上 **99.9% 的单块退化是「无谓语候选」**。
分句器找不到谓语，只能把整句退回成一个无标记块。

根因不是「算法错」，而是**动词表太小**：

```
DEFAULT_VERBS = 208 条
  ├─ 双字 202 条
  └─ 单字   6 条（吃 哭 坐 睡 站 笑）
```

汉语单字动词（看/说/走/买/拿/做/去/来）**几乎全缺**。
一份 208 条的词表不可能覆盖真实语料。

## 做法：用体标记自动抽

「动词 + 着/了/过」是汉语的体形态标记，可靠度远高于猜：

```
看着 -> 看      笑了 -> 笑      说过 -> 说
```

`tools/harvest_verbs.py` 扫语料，`tools/build_verb_table.py` 生成
`data/verb-table.json`。

### 噪声过滤（实测更新）

直接抽噪声很大。前 40 名里就有 `不过`、`接着`、`向着`、`为了`、`太大了`。
规则和依据：

| 规则 | 例子 | 依据 |
|---|---|---|
| 连词/介词黑名单 | `不过` `接着` `为了` `除了` | `过`/`着` 是词素不是体标记 |
| 代词黑名单 | `什么` `怎么` `自己` | 不是动词 |
| 程度副词开头 | `太大了` `真好看` | 形容词 |
| 粘着前字 | `的看` `只不` `头看` `受不` | 切到了词中间 |

### 频次门槛是关键

| 门槛 | 条数 | 结果 |
|---|---|---|
| 30 | 5,354 | ❌ **14 个回归测试失败**（`认真` 38 次、`原因` 71 次被当动词） |
| 500 | 428 | ✅ 全部通过，且有效 |

低频候选噪声占绝大多数：`认真`(38)、`原因`(71) 这类词虽然**能**带体标记，
但语料里出现得太少，抽出来多半是别的原因。

## 效果

`tools/diagnose_chunker.py --limit=30`（各 30 个文件）：

| 语料 | 208 条 | 428 条 | 改善 |
|---|---|---|---|
| 普通小说 | 56.6% | **41.4%** | −15.2pp |
| 成人语料 | 64.5% | **50.9%** | −13.6pp |

对照：仅修分句（引号/碎片/连词粘合）只从 66.7% 降到 57.7%（−9pp）。
**动词表是更大的杠杆。**

## 但默认关闭

```python
SentenceChunker()                    # 208 条，原行为
SentenceChunker(extended=True)       # 428 条
```

原因：扩展表引入了两类**新**的切分错误，回归锁还没解决。

### 错误 1：`带` 抢了 `离开`

```
输入：日本代表带着满意的笑容离开会场
208 条：A[日本] E[代表] B[带着满意的笑容离开会场]     ← 至少 E 是对的
428 条：A[日本] E[代表带着] B[满意的笑容离开会场]      ← E 错了
```

`带` 进了表，它在 `带着` 处先命中，`离开` 就没机会。
这说明**单字动词和"v+着"降级规则（`[张]` §3）有冲突**：
§3 说 `v+着` 的首动词应降为辅块，但要先知道 `代表` 是 E 才行。

### 错误 2：`分析问题` 被整体当 E

```
输入：他正在分析问题
208 条：A[他正在] E[分析] B[问题]
428 条：A[他正在] E[分析问题]                       ← B 丢了
```

`问题` 不在动词表里，但 `_predicate_start` 的回溯把 E 的右边界推到了句末。
这是 `_predicate_start` 的既有缺陷，扩展表只是让它更常触发。

## 结论

- **扩展表值得用**（退化率收益 −15pp 是实打实的）。
- **但不能直接开**，要先修 `_predicate_start` 的右边界和 `v+着` 的优先级。
- 等这两个修好，再考虑把 `extended=True` 变成默认。

## 复现

```bash
# 抽动词表（约 3 分钟）
python tools/build_verb_table.py

# 对照退化率
python tools/diagnose_chunker.py --limit=30
python tools/diagnose_chunker.py --limit=30 --extended
```
