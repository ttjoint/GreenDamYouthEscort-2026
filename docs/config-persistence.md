# 配置持久化（M7，已实现）

`src/green_dam/config.py`。测试 `tests/test_config.py`，26 项。

## 1. 保留什么、修什么

原厂写 `xconfigs.dat` 的方式（`analysis/probe/p15`，`WriteFileBin` @ `0x40ad67`）：

```
open("xconfigs.dat", "wb") → 写 268 字节 → 关闭
```

**保留**：格式。268 字节小端 uint32 数组，与 `sys.dat` 逐字节同构，导入器
和任何旧工具都能读。

**修掉**：写入路径的三个缺陷。

| 原厂问题 | 后果 | 本实现 |
|---|---|---|
| 无临时文件，直接覆写 | 写入中断 → 文件截断 → 静默回落默认 | 同目录临时文件 + `fsync` + `os.replace` |
| 无校验 | 越界值也能写进去 | 写前 `validate()`，写后**读回再校验** |
| 无元信息 | 不知道谁写的、什么状态 | 旁挂 `.meta.json` |

## 2. 为什么用旁挂文件而不是文件头

67 个槽全部有归属：1–25 命名，26–67 保留且必须为 0。**没有空间放版本号或
魔数**。加文件头会破坏与原厂文件的兼容性。

所以元信息放在 `<name>.meta.json`：旧工具完全忽略，新工具可读。

## 3. 校验规则

```python
validate(array, strict=True)
```

| 规则 | strict | 说明 |
|---|---|---|
| 恰好 67 槽 | ✔ | 结构 |
| 保留槽（26–67）必须为 0 | ✔ | 结构 |
| 命名槽值 ∈ {0,1,2,3,5,14} | ✔ | 值域 |
| 同上前三条，跳过值域 | ✘ | 读真实文件时用 |

**为什么读的时候默认不严格**：原厂产出的文件对自身内容有权威性。因为它
"看起来值不寻常"就拒绝读取，会让导入器读不了真实数据。但**结构性错误
（尺寸错、保留槽非零）始终拒绝**——那不是"值不寻常"，是文件坏了。

## 4. 原子写入

```
临时文件（同目录）→ 写 → flush → fsync → os.replace
```

- 同目录才能保证 `os.replace` 是原子的（跨卷会退化成复制）
- 任何失败路径都删除临时文件，不留垃圾（有测试断言目录里无 `.tmp` 残留）
- 写后**读回比对**：短写或坏扇区在这里暴露，而不是下次启动

写前还做一次 encode/decode 往返自检：如果不一致，bug 在本模块，不在磁盘。

## 5. 按策略号改值（不是按数组下标）

```python
set_values(arr, {5: 1})   # 策略 5 → 内部 index 4
```

`{4: 1}` 会被解释成"策略 4"，而不是"索引 4"。传索引会差一位且极难发现，
所以键必须是策略号，`slot_index()` 负责换算并对越界报错。

## 6. 默认值防漂移

`default_for_fresh_install()` 给出 CD 上 `sys.dat` 的原始值。

它内部有一张 `_SHIPPED_VALUES` 表，是**手抄**的，因此有漂移风险。为此：

- `test_defaults_match_the_shipped_blob_exactly` —— 与真实 `sys.dat` 逐值比对
- `test_shipped_values_table_covers_nonzero_slots` —— 表键必须等于 `SHIPPED_NONZERO`

任何人改动其中一边而忘了另一边，测试立刻失败。

## 7. 侧挂文件里的诚实标注

```json
"attested": {
  "slot_names": true,
  "index_is_slot_minus_one": true,
  "score_to_action": false
}
```

`score_to_action: false` 是刻意写的：原厂"分 → 动作"的映射仍未还原。一个
配置文件若宣称比代码更确定，就是文档与证据脱节的另一种形式。

`nonzero` 只列**策略号 ≤ 25** 的槽，保留槽即使非零也不会被当成"已知策略"
展示（虽然校验会先拒绝这种文件）。

## 8. 验收（26 项）

| 组 | 覆盖 |
|---|---|
| 出厂默认 | 与 sys.dat 逐值相等、表键完整、通过严格校验 |
| 校验 | 保留槽非零、值域越界、槽数错 |
| 改值 | 按策略号、不改原对象、非法策略号、保留槽不可设、结果被校验 |
| 存读 | 往返、**字节与 sys.dat 完全相同**、268 字节、旁挂文件、可跳过、无临时残留、非法不写 |
| 读 | 缺失、截断、真实 xconfigs、默认宽松、结构错误仍拒 |
| 路径 | 旁挂文件与主文件同目录 |
