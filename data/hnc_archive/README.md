```

B  = XB + YB + YC       良性分解
RB = RB1 RB2            可分可合
YC = YCB + YCC          对象内容分解
```

### 基本句类表（附表 2 原文，57 种）

```
XJ   作用句        P J  过程句       TJ   转移句      YJ   效应句
RJ   关系句        SJ   状态句       DJ   判断句      jDJ  基本判断句

一级子类示例：
X1J 承受句  X2J 反应句  X3J 免除句  X4J 约束句
T1J 接收句  T2J 物转换句 T3J 信息转换句 T49J 交换句
```

语句物理表示式（**这些就是 chunker 应该产出的 pattern**）：

```
XJ      = A + B + C
T3J     = TA + T3 + TB + T3C
XYJ     = A + X + B + YC        YC = E + EC
XY02J   = A + XY02 + B + YB2    （作用句 × 双对象效应句，规范格式）
XRm110J = A + XR + RB2 + RC     （作用句 × 单向扩展关系句）
T2b*XJ  = TA + T2b + TB2 + X + B（自身转移句 × 作用句，复合句）
```

注意 `T3J = TA + T3 + TB + T3C`：转移句的 A 和 B 是**带下标**的（`TA`/`TB`），
不是裸 `A`/`B`。这解释了 `hnc.py` 里 `!31116` 这类码为什么要有 6 位——
每一位对应一个块的位置与角色。

### 辅块（论题 7）

`book307.htm` 给出辅块判定的三条原则，原文：

> 第一，辅块的位置具有"不定之定"的基本特征，这个"定"就是它**绝不会
> 出现在 E 块之后**，这是汉语的一个十分可爱的特点。
>
> 第二，辅块之是否带标记**不理会句类格式之变**，这是辅块之有别于主块的
> 一个极为可爱的特点。
>
> 第三，**不带标记的辅块必然是以 K(jm) 为内容的条件辅块**。其中主要是
> 时间条件辅块。

**第一条直接可写进代码**：辅块不出现于 E 之后 → chunker 在找到 E 之后
不应再切出辅块。这与当前 `chunker.py` 的行为一致，但此前是"碰巧一致"，
现在有文献依据。

**第三条同样可落地**：无标记辅块 → 条件辅块（Cn）。当前实现把无标记
辅块判为 Ms（方式），与文献不符，**需要修正**。

另一条重要论断（论题 7 答 3）：

> 在工程意义上，辅块也可以这样定义：**辅块是句类代码之外的语义块**

这是"非主即辅"从权法。反过来还有"非辅即主"从权法。文献明确说两者
"可以交替使用"。

## 抓取与复现

```bash
# 全站发现 + 抓取
python tools/fetch_hnc_archive.py --out data/hnc_archive --discover

# 断点续传（跳过已有非空文本）
python tools/fetch_hnc_archive.py --out data/hnc_archive \
    --plan data/hnc_archive/plan2.txt --resume
```

已知问题：

- 页面声明 `charset=gb_2312-80`，但 archive.org 回放时按 UTF-8 发送。
  必须取原始字节再按 GBK 解码，`requests.text` 会得到乱码。
- archive.org 常在 TLS 握手阶段直接断连
  （`SSL: UNEXPECTED_EOF_WHILE_READING`），不是 404，需要重试。
- Wayback 工具栏注入在 `<body>` **内部**，正文须从
  `END WAYBACK TOOLBAR INSERT` 之后开始。
- 约 25% 页面在快照里确实缺失（404），这是存档本身的缺口，无法补齐。
